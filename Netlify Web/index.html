04 bước đơn giản
01

Tải file cài đặt

Nhấn nút "Tải xuống" ở trên để tải file .exe về máy tính của bạn.

02

Chạy file Setup

Chạy file Setup.exe và làm theo hướng dẫn. Đóng Revit trước khi cài.

03

Mở Revit - Load Addin

Khi hiện thông báo Load Addin thì chọn Always Load để Revit load HDBIM Tools.

04

Đăng ký License

Tab HDBIM Tools sẽ xuất hiện trên Ribbon. Chọn chức năng License Manager tại Panel HDBIM để đăng ký License key và sử dụng Tools.
