Cài đặt trong
04 bước đơn giản

Đóng Revit trước khi cài và chọn Always Load để plugin tải mỗi lần khởi động.

01

Tải file cài đặt

Nhấn nút "Tải xuống" ở trên để tải file .exe về máy tính của bạn.

02

Chạy file Setup

Chạy file Setup.exe và làm theo hướng dẫn. Đóng Revit trước khi cài.

03

Mở Revit - Load Addin

Khi hiện thông báo Load Addin thì chọn Always Load để Revit load HDBIM Tools.

04

Đăng ký License

Tab HDBIM sẽ xuất hiện trên Ribbon. Chọn chức năng Purchase tại Panel HDBIM để đăng ký Gói dùng thử.

License Key sẽ được gửi về Email đăng ký. Nhập License Key vào License Manager để kích hoạt và sử dụng Tools.

Chọn gói phù hợp với nhu cầu của bạn

Linh hoạt theo nhu cầu sử dụng. Tất cả các gói đều bao gồm cập nhật và hỗ trợ kỹ thuật.
